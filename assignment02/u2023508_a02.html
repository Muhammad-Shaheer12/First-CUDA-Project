Task 02 — CPU Matrix Multiplication

Objective

Implement matrix multiplication (C = A × B) on the CPU in C++, supporting potentially non-square matrices. The program reads two matrices from an M2X-format file and writes the result.

Algorithm

Classic triple-nested loop: for each element C(i, j), compute the dot product of row i of A and column j of B.

for i in 0..M:
    for j in 0..N:
        sum = 0
        for p in 0..K:
            sum += A(i,p) * B(p,j)
        C(i,j) = sum

Task 03 — Naive CUDA Matrix Multiplication

Objective

Port the CPU matrix multiplication to a naive CUDA kernel where each thread computes one element of the output matrix C.

Kernel

__global__ void matmul_kernel(const double* A, const double* B, double* C,
                              unsigned M, unsigned K, unsigned N) {
    unsigned row = blockIdx.y * blockDim.y + threadIdx.y;
    unsigned col = blockIdx.x * blockDim.x + threadIdx.x;
    if (row < M && col < N) {
        double sum = 0.0;
        for (unsigned p = 0; p < K; ++p)
            sum += A[row * K + p] * B[p * N + col];
        C[row * N + col] = sum;
    }
}

Grid/block configuration: 2D blocks of 16×16 threads, grid sized to cover the output matrix dimensions.

Computational Intensity (Naive)

For square N×N matrices:

MetricValue
Total FLOPs2 · N³ (N multiply-adds per element, N² elements)
Global memory trafficEach thread reads N doubles from A + N from B + writes 1 → N² · (2N+1) · 8 bytes
Computational Intensity≈ 0.125 FLOP/byte (= 1/8)
The naive kernel is memory-bound — each loaded value is used only once and there is no data reuse across threads. Tiling (Task 05) addresses this by loading tiles into shared memory.

Task 05 — Tiled GPU Matrix Multiplication

Objective

Implement a tiled (shared-memory) matrix multiplication kernel and compare its performance against the naive GPU and CPU implementations.

Tiled Kernel Design

Each thread block loads a TILE×TILE sub-matrix of A and B into shared memory, computes partial dot products, then advances to the next tile pair. This converts global memory accesses to shared memory accesses within each tile.

__global__ void matmul_tiled_kernel(const double* A, const double* B, double* C,
                                    unsigned M, unsigned K, unsigned N, unsigned TILE) {
    extern __shared__ double smem[];
    double* As = smem;
    double* Bs = smem + TILE * TILE;
    // ... load tile, __syncthreads(), accumulate, __syncthreads() ...
}

Maximum Tile Size Analysis

ConstraintCalculationLimit
Shared memory per block 2 × T² × 8 bytes ≤ 49 152 T ≤ 55
Max threads per block T² ≤ 1024 T ≤ 32
Maximum tile size 32 × 32
The binding constraint is maxThreadsPerBlock = 1024 (32² = 1024), not shared memory (which could support up to T=55 for doubles).

Formula: Intensity = T / 8 FLOP/byte. Each tile load brings 2·T² doubles (16·T² bytes) and contributes 2·T³ FLOPs.
